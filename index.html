Ayuda de Uso

📝 Editor Principal (TinyMCE)

Editor de texto enriquecido para crear y editar contenido con formatos como:

  • Estilos: Negrita, cursiva, subrayado
  • Listas: Numeradas y sin numerar
  • Tablas: Inserta y edita tablas
  • Imágenes: Se guardan en Base64 (dentro del documento)
  • Vínculos: Agrega enlaces a textos
  • Código: Visualiza el código fuente HTML

💾 Botones de Toolbar Principal

  • Copiar HTML: Copia el contenido HTML actual al portapapeles
  • Descargar HTML: Descarga el contenido como archivo .html
  • Guardar como nota: Guarda el contenido actual en una nota reutilizable
  • Notas: Abre/cierra el panel lateral de notas
  • Exportar XML: Descarga todas las notas en formato XML
  • Importar XML: Carga notas de un archivo XML anteriormente exportado

📌 Panel Lateral (Notas Reutilizables)

Crear una nota:

  1. Escribe el contenido en el editor TinyMCE
  2. Completa el Título en el panel lateral
  3. Selecciona una Categoría
  4. Elige un Color para la tarjeta
  5. Haz clic en "Guardar del editor"

Acciones de una nota:

  1. Haz clic en "Cargar nota" para abrirla en el editor y poder actualizarla
  2. Haz clic en "Copiar nota con formato" para copiarla como al usar Ctrl+C en el editor
  3. Haz clic en "Borrar" para eliminarla

Eliminar una nota:

  1. Haz clic en "Borrar" en la tarjeta de la nota
  2. La nota se eliminará inmediatamente

🏷️ Categorías Dinámicas

Puedes crear tus propias categorías:

  1. Haz clic en el botón "+" junto al selector de categoría
  2. Escribe el nombre de la nueva categoría
  3. Presiona Enter o haz clic en "Guardar"
  4. Puedes usar esta categoría en tus notas

🎨 Colores de Notas

Cada nota puede tener un color diferente para organizarlas visualmente:

  • 🟨 Amarillo
  • 🟩 Verde
  • 🟦 Azul
  • 🟥 Rosa/Rojo
  • 🟪 Morado

💾 Persistencia de Datos

Las notas se guardan automáticamente en localStorage del navegador:

  • Al cerrar y abrir el navegador, tus notas se mantienen
  • Para hacer una copia de seguridad, exporta a XML
  • Para restaurar notas, importa el archivo XML

📊 Filtrar por Categoría

Los botones de filtro en el panel te permiten:

  • Ver todas las notas (botón "Todas")
  • Ver solo notas de una categoría específica
  • Reordenar notas arrastrándolas entre ellas

💡 Consejos

  • Usa diferentes colores para categorías visuales
  • Las imágenes insertadas en el editor se guardan en Base64
  • Exporta regularmente tus notas como backup
  • Puedes editar notas rápidamente desde las tarjetas
  • El contenido del editor se mantiene mientras trabajas
